### `$ ls ~/projects`

**[anpasser](https://github.com/farhanakhtar0x66/anpasser)** — `binary analysis / compilers / experimental`  
Research tooling for ahead-of-time transformation of Windows games into native Linux programs. Focused on recoverable behavior and reproducible verification; **not** a universal game converter.

**[hayate](https://github.com/farhanakhtar0x66/hayate)** — `android / offline / input method`  
A lightweight Android flick keyboard with suggestions, clipboard features, and a programmer mode. Designed to work without network access.

**[jalnet-submission](https://github.com/farhanakhtar0x66/jalnet-submission)** — `typescript / android / cedar`  
A map-first water-incident reporting prototype with local Cedar authorization, private evidence handling, and route warnings. Local/demo scope; cloud deployment is unverified.

**[dotfiles](https://github.com/farhanakhtar0x66/dotfiles)** — `macos / shell / catppuccin`  
My macOS setup: AeroSpace, SketchyBar, Ghostty, tmux, Zsh, and a lot of Catppuccin Mocha.
