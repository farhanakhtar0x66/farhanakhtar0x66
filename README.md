<a id="selected-work"></a>
### `$ ls ~/projects`

#### [anpasser](https://github.com/farhanakhtar0x66/anpasser)
`Rust` `binary analysis` `compilers`

Research into turning Windows game code into native Linux programs ahead of time. Explores code recovery, compiler passes, and native API migration, with Windows/Linux behavior comparisons to check the results. **Experimental; not a universal game converter.**

[Explore the project](https://github.com/farhanakhtar0x66/anpasser#why-anpasser) · [See the evidence](https://github.com/farhanakhtar0x66/anpasser#evidence-not-hype)

#### [hayate](https://github.com/farhanakhtar0x66/hayate)
`Java` `Android` `offline-first`

An Android keyboard that fits the alphabet onto six letter keys. Tap or flick to type, use offline suggestions, and switch to a programmer mode for code. **No network permission.**

[How it works](https://github.com/farhanakhtar0x66/hayate#type) · [Android releases](https://github.com/farhanakhtar0x66/hayate/releases)

#### [terminal-ascii-screensaver](https://github.com/farhanakhtar0x66/terminal-ascii-screensaver)
`Python` `Linux / macOS` `terminal tooling`

Editable ASCII artwork and text effects for the terminal. An optional automatic mode covers long-running tasks, then restores the terminal when input or task completion needs your attention.

[Try it](https://github.com/farhanakhtar0x66/terminal-ascii-screensaver#install) · [Make it your own](https://github.com/farhanakhtar0x66/terminal-ascii-screensaver#customize-your-artwork)
