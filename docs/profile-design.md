# Profile direction

Keep the approved static AKHTAR / Creation of Adam header as the distinctive
visual element. Use native GitHub text underneath it so the profile is readable,
searchable, accessible, and useful on mobile without depending on a widget host.

The profile now leads with a short introduction, three selected projects,
a dated C++/DSA learning section, an honest toolbox, and a direct contact link.
The secondary projects remain accessible in a disclosure. No skill percentages,
problem counts, streaks, visitor trackers, or unverified coding-profile links.

## Inspiration consulted

The [awesome profile collection](https://github.com/abhisheknaiidu/awesome-github-profile-readme)
was used to find these examples:

- [Orhun](https://github.com/orhun/orhun): clear technical identity and prominent
  projects. The principle is applied here without copying wording or statistics.
- [Maximous Black](https://github.com/maximousblk/maximousblk): direct introduction
  and links to concrete work. This profile uses curated projects rather than an
  automated activity feed.
- [fnky](https://github.com/fnky/fnky): a coherent personal aesthetic. The existing
  terminal artwork supplies that identity here; animation remains out of scope.

## Content grounding

Project descriptions were checked against their own READMEs: anpasser, hayate,
terminal-ascii-screensaver, dotfiles, and JalNet. Experimental and demo limits
remain visible. Existing LEX and hackathon-kit descriptions are retained.

The owner said they will start DSA in C++ next week. On 24 October 2026, that is
the week of 26 October. It is presented as a future learning plan, not work
already completed. A public `dsa-cpp` repository was subsequently created at the owner's request,
and the supplied LeetCode username was verified before adding the activity card.
The roadmap remains a proposed sequence; actual LeetCode activity is sourced
from the platform.
